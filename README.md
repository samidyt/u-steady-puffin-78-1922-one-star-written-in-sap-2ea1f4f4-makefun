A [make.fun](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) bounty entry: one funny one-line 1-star review, written in the voice of a houseplant reviewing its human owner.

## The entry

`main.py` writes a single line — under 280 characters, one line, with a specific plant's-eye grievance and a reason for the single star — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

It validates the line against the gate (one line, 1–279 characters, non-blank) before writing, then prints the line and its character count.
